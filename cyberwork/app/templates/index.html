LOCAL NETWORK / DEFENSIVE UTILITIES

Network tools

Low impact

These tools are restricted to private/local IP addresses. Use only on your own device or network. No passwords are collected.

Ping a local host


        
Open-port exposure check
Checks a fixed set of 15 common ports on one private IP. Not a full network sweep.

        
Nearby Wi-Fi inventory
Windows 10/11 only. Reads nearby SSIDs and signal details using Windows netsh; never reads saved passwords.

      

      
NOT INCLUDED
Offensive or privacy-invasive tools
DoS/DDoS generators, brute-force login attempts, fake/evil-twin Wi-Fi creation, phone-number crawling, covert camera hunting, and unbounded fuzzing are intentionally not included. For authorized web testing, use a lab target and a defined scope.
